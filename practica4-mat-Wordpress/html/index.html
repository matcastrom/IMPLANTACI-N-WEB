🐳 Cómo utilizar Docker Compose

Docker Compose permite definir y ejecutar varias aplicaciones en contenedores Docker con un solo archivo de configuración: docker-compose.yml. Es ideal para proyectos con base de datos, backend y frontend.

1. Instalación

Docker Compose viene incluido con Docker Desktop en Windows y macOS. En Linux, puedes comprobar si está instalado con: 

docker compose version

Si no está instalado, sigue la documentación oficial de Docker para tu distribución de Linux.

2. Crear el archivo docker-compose.yml

Crea una carpeta para tu proyecto y, dentro, un archivo llamado docker-compose.yml. Este archivo describe los servicios o contenedores que quieres ejecutar. 

version: "3.8"

services:
  web:
    image: nginx:latest
    ports:
      - "8080:80"

  db:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: ejemplo123
      MYSQL_DATABASE: mibasededatos
    volumes:
      - datos_mysql:/var/lib/mysql

volumes:
  datos_mysql:
💡 Explicación:

- services: cada contenedor que se va a crear.
- image: imagen oficial de Docker que se utilizará.
- ports: puerto de tu PC → puerto del contenedor.
- environment: variables de configuración.
- volumes: guardan datos aunque el contenedor se borre.

3. Comandos básicos

Comando Para qué sirve
docker compose up Crea y arranca todos los contenedores.
docker compose up -d Los arranca en segundo plano, sin bloquear la terminal.
docker compose down Detiene y elimina los contenedores y redes creados.
docker compose ps Muestra los contenedores activos del proyecto.
docker compose logs Muestra los registros o logs de los servicios.
docker compose logs -f Muestra los logs en tiempo real.
docker compose restart Reinicia los servicios.
docker compose stop Detiene los contenedores sin eliminarlos.
docker compose start Vuelve a arrancar contenedores detenidos.
docker compose build Construye imágenes definidas con un Dockerfile.

4. Ejemplo práctico

Guarda el archivo docker-compose.yml y ejecuta en la terminal, dentro de esa carpeta:

docker compose up -d

Luego abre en tu navegador:

http://localhost:8080

Deberías ver la página inicial de Nginx.

Para comprobar qué contenedores están funcionando:

docker compose ps

Para detener y eliminar todo lo creado:

docker compose down

5. Usar un Dockerfile con Compose

Si tu aplicación necesita una imagen propia, crea un Dockerfile y referencia la carpeta con build: 

services:
  app:
    build: .
    ports:
      - "3000:3000"

Una estructura recomendada sería:

mi-proyecto/
├── Dockerfile
├── docker-compose.yml
└── app/
    └── index.js

6. Consejos importantes

  • Usa -d para ejecutar los contenedores en segundo plano.
  • Guarda los datos importantes en volumes.
  • Usa un archivo .env para contraseñas y datos sensibles.
  • Los contenedores del mismo docker-compose.yml pueden comunicarse usando el nombre del servicio, por ejemplo db:3306.
  • Ejecuta siempre los comandos desde la carpeta donde está el docker-compose.yml.
